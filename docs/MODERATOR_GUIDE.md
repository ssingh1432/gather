# Gather — Moderator Guide

## Report categories (14)
spam · fake_account · harassment · hate_speech · violence · terrorism · child_abuse · adult_content · copyright · scam · impersonation · self_harm · drugs · other

## Triage order
1. **child_abuse** — remove immediately, preserve evidence, escalate to an admin the same hour for legal handling. Never download or share the material.
2. **terrorism / violence / self_harm** — act fast; for self_harm prioritise welfare (a supportive notification), then policy.
3. scam / impersonation / harassment / hate_speech
4. copyright (needs a notice: who owns it, URL, good-faith statement)
5. spam / adult_content / drugs / other

## Actions (use the lowest that fixes the harm)
| Action | When |
|---|---|
| Dismiss report | No violation; add a note |
| Hide / remove content | Violation, user may be educated |
| Warning | First minor offence |
| Strike | Clear violation. 3 strikes → 3-day suspension, 5 → 14 days, 7+ → permanent ban (automatic) |
| Suspend | Repeated or serious, time-boxed |
| Ban | Severe or evasion; admin review recommended |
Severity can add more than one strike. Reinstating does not clear strikes.

## Every decision
- Add a **moderator note** (what rule, why).
- Attach **evidence** (private bucket `moderation-evidence`).
- Check for mass-report abuse (many reports from new accounts); the system dampens it, but use judgment.
- Notifications to the user go out automatically (moderation alert, report update).

## Copyright and flagged media
Copyright notices and counter-notices are resolved by staff via the RPCs in COPYRIGHT_WORKFLOW.md. Media flagged by the scanner is quarantined (post hidden) — review it and confirm or mark a false positive (MEDIA_SCANNING.md). Never forward child-abuse material; escalate to an admin.

## Appeals
Users appeal a specific action (`submit_appeal`). The reviewer must be a different moderator than the one who acted when possible. Outcomes: uphold, reduce, reverse (reinstate). Record the reason; the user is notified.

## Community moderators
Community roles/permissions are separate (community bans, warnings, keyword filters, moderation queue). Platform moderators can override.

## Privacy
Only open what you need. Do not copy personal data out of the system. Legal or police requests go to an admin — never answer them yourself.
